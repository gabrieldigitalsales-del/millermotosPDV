# PDV MILLER MOTOS

Programa em React + Vite para vendas de peças de moto, com layout clássico tipo sistema de oficina.

## Funções principais

- Cadastro de clientes
- Cadastro de produtos/peças
- Venda de balcão com carrinho
- Cupom imprimível
- Pix com QR Code
- Configurações da empresa: CNPJ, e-mail, telefone, endereço e chave Pix
- Histórico de vendas
- Relatórios básicos
- Backup e restauração dos dados
- Dados salvos no navegador pelo localStorage

## Como rodar

```bash
npm install
npm run dev
```

Abra o endereço exibido no terminal, normalmente:

```text
http://localhost:5173
```

## Observação

Esse sistema funciona localmente no navegador. Para multiusuário, emissão fiscal real, banco de dados externo ou integração com impressora térmica USB/rede, o próximo passo é adicionar um backend.
